# Data

`sample/tickets.csv` is a deterministic synthetic development dataset generated by
`smartdesk generate-sample`. It exists to verify the complete pipeline without
redistributing third-party data.

It must **not** be used to claim production model quality. Repeated templates make the
classification task intentionally simple. A later milestone will add a licensed public
dataset, a data card, stronger leakage checks, and a human-reviewed Vietnamese evaluation set.

Expected columns:

| Column | Meaning |
|---|---|
| `ticket_id` | Unique immutable ticket identifier |
| `text` | Ticket content |
| `category` | One of the six supported categories |
| `priority` | `LOW`, `MEDIUM`, `HIGH`, or `URGENT` |
